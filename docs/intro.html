随手找 / 随性人啊02

从一个关键词开始

搜索文件名，也搜索所在路径。

文件名线索供热

查找名称或所在目录包含“供热”的项目

组合线索冷暖站 md

用空格组合关键词；多个词可以分布在名称和父目录中

搜索名称与路径；文档正文、图片文字不在当前搜索范围内。

随手找 / 随性人啊03

结果分类

先选类型，再看结果。

文件夹文档图片音频视频应用压缩包代码其他
找目录，选“文件夹”。
找素材，选“图片”或“视频”。

每条结果都有类别标注；按后缀与目录属性识别，.app 应用包单独归为“应用”。

随手找 / 随性人啊05

妙用一 · 找回工作资料

项目名 + 文件线索，比完整标题更容易记。

冷暖站 恢复

输入记得项目叫“冷暖站”，资料与“恢复”有关

筛选选择“文档”，缩小范围

处理打开资料，或在 Finder 中查看同目录附件

场景示例：关键词是否命中，取决于已索引的名称与路径。

随手找 / 随性人啊06

妙用二 · 找视频与配音

一个项目名，切换两种素材。

项目名 → 素材类型

选择“视频”

寻找成片、镜头、预览文件
例如 MP4、MOV、MKV

选择“音频”

寻找配音、录音、音乐文件
例如 WAV、MP3、FLAC

适合 B 站创作：复用项目名，把不同目录中的素材找出来。

随手找 / 随性人啊07

妙用三 · 找目录，接着干活

记住项目，不必记住每个文件。

项目名 + 文件夹

找项目输入项目名，筛选“文件夹”

进目录打开结果，继续整理或编辑

交给工具复制路径，用于终端命令或本地工具

文件夹分类不包含 .app 应用包；要找软件，切换“应用”。

随手找 / 随性人啊09

第一次使用

先建立索引，再随手搜索。

01

选择索引位置

从常用的资料、下载和项目目录开始

02

等待首次扫描完成

支持添加多个位置，也可建立全盘索引

03

⌥ Space 呼出，输入关键词

文件变化自动更新索引；方向键选结果，Enter 打开

全局快捷键可能被其他软件占用；受保护目录可能需要完全磁盘访问权限。
