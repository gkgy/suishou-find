# 随手找

**文件多，也能随手找到。** 一个用 Rust 编写的 macOS 本地文件名与路径搜索工具。

记得标题里的一个词，或者文件所在的项目名，就从这个线索开始搜索。再按文件夹、文档、图片、视频等类型筛选，找到后直接打开、在 Finder 中定位，或复制完整路径。

## 它能做什么

- **名称搜索**：默认只匹配文件或文件夹名称；勾选顶部“同时匹配路径”后，父目录名称也参与搜索。支持中文、英文、扩展名和各级目录名关键词；英文采用 ASCII 大小写不敏感匹配。
- **组合关键词**：用空格分隔多个词，例如 `冷暖站 md`。默认所有词均需出现在名称中；开启“同时匹配路径”后，词也可以出现在父目录中，最多使用 8 个去重后的关键词。
- **分类筛选**：全部、文件夹、文档、图片、音频、视频、应用、压缩包、代码、其他；结果显示类型图标。
- **全盘或指定位置索引**：可添加多个目录；全盘扫描包含本地磁盘及本地外接盘。
- **修改日期与排序**：每条结果显示修改日期，默认“最新修改优先”，点击“修改日期”表头切换“最早修改优先”，点击“名称”按名称升序。日期排序先比较全部命中项，再显示前 500 条；缺少日期的项目排在末尾。
- **紧凑表格**：参考 Everything 的布局，顶部搜索框、左侧分类、右侧名称 / 所在路径 / 修改日期三列；白底深色字，选中行整行蓝底白字，长文本省略并可悬停查看完整路径。
- **自动更新**：监听已索引位置的文件变化，后台更新索引；启动时先显示已有索引，再在后台处理积累的变更记录。
- **随时呼出**：`⌥ Space`（Option + 空格）显示或隐藏窗口。
- **找到就处理**：单击选中、双击打开；方向键选择、Enter 打开；右键在 Finder 中显示或复制完整路径。
- **本地运行**：索引和查询在电脑上完成，无需账号、云端服务或 AI 模型。

## 下载与首次使用

当前发布的 App 为 **Apple Silicon / arm64** 版本，最低系统版本声明为 macOS 13；已在 M5 Max Mac Studio 上实际运行验证。其他 macOS 版本及 Intel Mac 尚未验收。

1. 从 [Releases](https://github.com/gkgy/suishou-find/releases/latest) 下载 `SuishouFind-v0.4.1-macOS-arm64.zip`。
2. 解压，将 **随手找.app** 拖到“应用程序”，然后打开。
3. 点击 **索引 → 选择位置…**，建议先选常用的资料、下载或项目目录。
4. 首次扫描完成后输入关键词，再按需要切换分类。

发行包采用临时签名，尚未经过 Apple 公证。macOS 可能提示无法验证开发者；若出现系统阻止提示，请按系统提供的“隐私与安全性 → 仍要打开”流程处理。受保护目录可能需要“完全磁盘访问权限”。如果快捷键被其他应用占用，窗口状态栏会提示。

## 几个顺手的用法

| 你记得什么 | 搜索与筛选 | 接下来做什么 |
|---|---|---|
| 项目名与资料主题 | 输入 `项目名 恢复`，选择“文档” | 打开资料，或在 Finder 查看同目录附件 |
| 视频项目名称 | 输入项目名，选择“视频” | 找成片、镜头和预览文件 |
| 配音对应的项目 | 输入项目名，选择“音频” | 找 WAV、MP3、FLAC 等声音素材 |
| 项目目录的名字 | 输入项目名，选择“文件夹” | 回到项目目录继续工作 |
| 某个软件名称 | 输入名称，选择“应用” | 查找 .app 应用包或安装包 |
| 要交给其他工具的文件 | 找到结果，右键“复制完整路径” | 粘贴到终端、脚本或本地工具 |

按项目目录名查找其中的文件时，请先勾选“同时匹配路径”。

以上是查询示例，实际命中取决于已索引的名称与路径。

## 搜索范围与分类规则

随手找默认搜索 **文件或文件夹名称**，勾选“同时匹配路径”才搜索父目录名称。搜索 `output` 并选择“文件夹”，只会显示名称含 `output` 的文件夹；开启路径匹配时，其子目录也可能命中。它不读取文档正文，不进行图片 OCR，也不做语义搜索；没有全文、拼音或模糊纠错功能。路径匹配以文件名和各级目录名为单位，跨目录分隔符的连续字符串（例如 `foo/bar`）当前不保证命中，建议改用 `foo bar`。

类别根据文件后缀和索引中的目录标记判断，不读取文件内容。`.app` 目录单独归为“应用”；其他目录归为“文件夹”。分类在获取结果上限前应用，因此不会只筛前 500 条普通结果。

每次最多显示 **500 条**。命中过多时可增加关键词或切换类型。修改日期排序覆盖当前搜索范围的全部命中项。名称排序也先比较全部命中项，再截取前 500 条；采用区分大小写的名称升序。空查询不列出所有文件。

## 本机实测

以下是 0.3.0 的历史搜索基准，不包含 0.4.0 新增的全结果日期排序开销。

2026-10-11，Mac Studio M5 Max / 64 GB，使用同一份 **1,931,183 项**索引快照。旧版与优化版在同一 release 基准程序中交替运行，预热 3 次、测量 15 次，以下为中位数。

| 查询 | 优化前 | 优化后 | 提速 |
|---|---:|---:|---:|
| `SCADA` | 40.344 ms | 4.620 ms | 8.73 倍 |
| `冷暖站 md` | 37.961 ms | 4.790 ms | 7.92 倍 |
| `扫码` | 25.986 ms | 3.824 ms | 6.79 倍 |
| `不存在xyz987` | 26.303 ms | 3.856 ms | 6.82 倍 |
| `pdf` | 1.384 ms | 1.245 ms | 1.11 倍 |

这些数值只衡量**内存索引查询耗时**，不包含启动、建索引或打开文件，也不代表所有电脑都能达到同样速度。少见关键词和组合词提升更明显，常见扩展名原本就很快。

优化复用了扫描得到的关键词匹配结果，父目录回退时不再重复搜索每个文件名；单关键词采用快速存在性匹配。索引格式与大小保持不变，每次查询增加约 1.9 MB 临时匹配掩码。

[完整基准数据](docs/benchmark-2026-10-11.csv) · 0.3.0 性能优化验证时，7 项库测试通过；12 组查询的完整结果与旧实现逐条一致，10 个类别逐条核对；截断查询检查数量与成员正确性。

## 从源码构建

需要 macOS、Rust 工具链和 Xcode Command Line Tools。项目使用 Rust 2024 edition；原验证工具链为 Rust 1.98.0。依赖版本固定在 `Cargo.lock`。

```bash
git clone https://github.com/gkgy/suishou-find.git
cd suishou-find
cargo test --locked --lib --bin miao-find
./scripts/build_app.sh
open dist/随手找.app
```

构建脚本默认使用临时签名；有自己的 Apple 签名证书时可设置 `SIGN_IDENTITY`：

```bash
SIGN_IDENTITY="你的签名身份" ./scripts/build_app.sh
```

复现查询基准时，使用你自己的索引快照：

```bash
cargo run --locked --release --bin bench-search -- /path/to/index-v3.bin
```

此命令只读取指定快照，比较完整结果及类别一致性，并输出耗时。仓库不包含作者的索引文件或文件清单。

## 本地数据

为保持与原“秒找”版本的索引兼容，内部应用标识仍为 `com.gkgy.MiaoFind`，Cargo 包名仍为 `miao-find`。

升级到 0.4.0 后，旧索引会在后台补充修改日期；完成前仍可搜索，排序控件暂时不可用，完成后自动启用最新排序。首次补充需要读取索引项目的文件元数据，耗时取决于磁盘、项目数量与权限；之后先读取本地日期缓存，并在后台核对文件元数据，以更新应用关闭期间发生的修改；保存文件时日期也会自动更新。

主索引仍为 MIAOIDX3，新增独立日期缓存 `modified-v1.bin`，无需重建原索引。索引位于 `~/Library/Application Support/com.gkgy.MiaoFind/`，窗口设置位于 `~/Library/Application Support/随手找/`。索引包含文件名和目录结构，建议只保留在自己的设备上。扫描范围受 macOS 权限约束；无法访问的位置不会被完整收录。网络挂载位置可手动选择，其扫描和监听表现取决于文件系统，尚未保证。
